**作成日:** 2026-03-01

## 背景と方針転換

### rsLoRA路線の失敗（exp30-31）
- exp30（rsLoRA, r=128, LR=2e-5, dropout=0.05, wd=0.1）: 0.625 → TOML 28%崩壊
- exp31（rsLoRA, r=128, LR=5e-5, dropout=0, wd=0.05）: 0.572 → CSV 20%壊滅
- 原因: rsLoRAのスケーリング α/√r = 128/√128 ≈ 11.3 が標準LoRA α/r = 128/64 = 2.0 の5.6倍
- **結論: rsLoRA+r128は断念。exp2ベースに回帰**

### Slack投稿者の0.8+達成要因（3名の共通点）
1. **SEQ_LEN=1024**（全員が言及。「0.8の壁突破の第一歩」）
2. **低めのLR**（投稿1,2が明言）
3. **強めの正則化**（dropout, weight_decay。投稿1,2,3が明言）
4. **大きめgrad_accum**（投稿2が明言。「勾配の純化」）
5. rsLoRAは投稿1のみ言及。投稿2は**rsLoRA無しで0.82+達成**

### 方針: 1回1変数、段階的に検証
exp30-31の教訓「7変数同時変更は原因特定不能」を踏まえ、1回の実験で変更するパラメータを1〜2個に限定する。

## 実験計画

| パラメータ | exp2 (0.751) | exp32 |

| r | 64 | 64 |

| rsLoRA | なし | なし |

**目的:** SEQ_LEN=1024の単独効果を測定。

#### パターンA: exp32 > 0.751（SEQ_LEN効果あり）

- 最良SFTモデルでDPO実施

#### パターンB: exp32 ≈ 0.751（SEQ_LEN単独では変化なし）
- exp33: SEQ_LEN=1024 + grad_accum=16 + dropout=0.05（組み合わせ効果を検証）
- exp34: LR微調整（3e-5〜4e-5）
- 最良SFTモデルでDPO実施

#### パターンC: exp32 < 0.751（悪化）
- exp2ベースに戻してDPO改善に専念
- DPO側のパラメータ探索（LR, β, データセット）
