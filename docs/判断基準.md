## 判断フロー

### 新データセットを試す場合
1. まず少量サンプル（10件）をダウンロードして目視確認
2. `<tool_call>` タグの有無をgrepで確認
3. 汚染がなければ小規模SFT（LR=5e-5, epoch=1）で検証

### スコア解釈
- **0.01未満の改善:** ノイズの可能性。再現性確認が必要
- **0.01〜0.05の改善:** 有意な改善の可能性。方向性は正しい
- **0.1以上の劣化:** データ汚染またはハイパーパラメータ崩壊。inference.jsonを即時検証

### 提出残り数による方針切替
- **残り20回以上:** 探索的な実験も可
- **残り10〜20回:** 有望な方向のみ探索
- **残り10回以下:** 確実性の高いパラメータ微調整のみ
- **残り5回以下:** ベスト設定の再現・微調整のみ
